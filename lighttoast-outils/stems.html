Un stem (KICK, caisse claire, basse…) : TOAST y repère toutes les attaques et les montre sur la frise (petits repères de couleur) : ce sont les pêches possibles. Sensibilité : plus haut = plus de repères. Écart mini : deux repères plus proches que ça sont fusionnés. Créer les pêches les pose toutes d'un coup (annulable avec Ctrl+Z). Le stem n'est pas gardé dans le projet : seuls ses repères le sont.

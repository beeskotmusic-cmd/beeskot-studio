BEESKOT · ÉCOUTE — la page pour faire écouter nos morceaux à l'extérieur
=========================================================================

C'est quoi ?
  Dans BEESKOT Studio › Bibliothèque › « Partager l'écoute », on coche des morceaux et on obtient un lien :
     https://ecoute.beeskot-music.workers.dev/<code>
  La personne voit le logo, la pochette, le titre et un lecteur. Seulement la version ★, rien d'autre.
  Pas de bouton de téléchargement. Le lien suit toujours la ★ du moment.
  « Révoquer » dans le logiciel = la page répond « Ce lien n'est plus actif » (en moins d'une minute).
  Date d'expiration choisie à la création : passée = « Ce lien a expiré » (vérifié par Cloudflare,
  même si aucun PC du groupe n'est allumé).

Pourquoi c'est solide
  La page est fabriquée chez Cloudflare (gratuit), pas chez Google : une personne connectée à
  plusieurs comptes Google n'a aucun problème. Le son et les pochettes passent par Cloudflare :
  l'adresse des fichiers du Drive n'est jamais montrée.

Ce qu'il y a chez Cloudflare (compte Beeskot.music@gmail.com, connexion avec GitHub)
  Un Worker nommé « ecoute » : son code = worker.js de ce dossier.
  Une variable secrète CLE_API = la clé gratuite Google (la même que dans
  BEESKOT Studio › Notes et retours › Externe › « La clé gratuite Google »).

Les écoutes et les extraits (depuis la 0.9.123)
  Extrait : dans « Partager l'écoute », menu « Morceau entier / Extrait de 30, 42, 60 s / autre ». Cloudflare n'envoie
  que le début du fichier (WAV et MP3 : coupé côté serveur, impossible d'écouter plus loin). Autres formats (m4a…) :
  la page s'arrête à la durée, mais le fichier n'est pas coupé.
  Écoutes : la page prévient Cloudflare quand un morceau a vraiment joué 10 s ; on compte par lien et par morceau.
  Rangé dans un « KV » gratuit de Cloudflare : Storage & Databases › KV › namespace « beeskot-ecoutes »,
  relié au Worker « ecoute » sous le nom ECOUTES (Worker › Settings › Bindings › KV namespace).
  Sans ce KV, la page marche mais ne compte rien. BEESKOT Studio lit les chiffres à …/<code>/stats.

Modifier la page plus tard
  Automatique : changer worker.js ici et push. GitHub › Actions › « Mettre à jour Cloudflare (ecoute) » s'en charge.
  Il faut une seule fois le secret GitHub CLOUDFLARE_API_TOKEN :
    a. dash.cloudflare.com › en haut à droite (profil) › My Profile › API Tokens › Create Token
       › modèle « Edit Cloudflare Workers » › Use template › Account Resources : Beeskot › Continue › Create Token › copier.
    b. github.com/beeskotmusic-cmd/beeskot-studio › Settings › Secrets and variables › Actions
       › New repository secret › Name : CLOUDFLARE_API_TOKEN › coller › Add secret.
  À la main (secours) :
  1. Changer worker.js ici.
  2. dash.cloudflare.com › Workers & Pages › ecoute › « Edit code » : tout remplacer par le nouveau worker.js › Deploy.
  Les images et polices viennent du dépôt GitHub (jsDelivr), figées sur un commit : ligne ASSETS en haut de worker.js.
